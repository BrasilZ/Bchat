Bchat is a plugin to [TShock](https://github.com/Pryaxis/TShock) similar to [NChat]([https://docs.nickuc.com/pt/nchat/about/]) from Minecraft, with global and local chat
this plugin is made to a survival servers and other purposes if you want.

Commands:
/d / global
chat local is a normal chat just type
